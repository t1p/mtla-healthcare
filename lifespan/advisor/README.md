# LifeSpan Advisor

Коммерческий лендинг для beta-версии low-touch сервиса `LifeSpan Advisor`.

## Позиционирование
`LifeSpan Advisor` — это beta-сервис персональной навигации по здоровью и долголетию для тех, кому не подходит плотное сопровождение режима.

## Роль MTLA Healthcare
MTLA Healthcare выступает как партнёр проекта: контекст, экспертиза, доверие и среда.

## Оффер
- бесплатный test drive;
- beta-доступ;
- для early adopters — приоритетный доступ к новым функциям и расширенная техподдержка.

## Отличие от LifeSpan MVP
- `mvp` — high-touch, удержание режима;
- `advisor` — low-touch, рекомендации и next steps на основе данных.

## Содержимое
- `index.html` — основная страница;
- `apply.html` — страница формы заявки;
- `styles.css` — стили лендинга;
- `form.css` — стили формы.
