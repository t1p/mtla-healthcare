## Проектная цель

MTLA Healthcare — проект по созданию линейки пилотов LifeSpan для помощи людям в удержании здорового режима и ритма жизни. Четыре формата: от низкого контроля (Advisor) до высокого сопровождения (Operator).

## Ключевые особенности

- **Advisor** (Low-Touch): спокойная data-driven навигация по здоровью без плотного контроля режима
- **Circle** (Групповой): 4-недельный пилот для участников ЗОЖ с агентским сопровождением
- **MVP** (Beta): beta-услуга удержания режима с персональным протоколом и ежедневной поддержкой
- **Operator** (High-Touch): персональный пилот с интенсивным сопровождением (Support/Directive/Commit режимы)

## Общая архитектура

Проект состоит из:
- `lifespan/` — основная директория пилотов
  - `index.html` — сводная страница всех пилотов
  - `styles.css` — базовые стили
  - `advisor/` — страницы и формы Advisor
  - `circle/` — страницы и формы Circle
  - `mvp/` — страницы и формы MVP
  - `operator/` — страницы и формы Operator

Каждый пилот содержит:
- `index.html` — основная страница описания пилота
- `apply.html` — форма заявки участия
- `form.css` — стили форм
- `styles.css` — стили страницы пилота
